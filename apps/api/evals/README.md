# AI 分析の評価

`semantic_diff.py` は、期待する見解を付けた固定の差異セット(`cases.json`)をモデルに渡し、どれだけ一致するかを表示する。

単体テストは「モデルが何を返しても壊れないこと」を保証する。ここで見るのは別のこと、つまり「モデルの返す見解が妥当か」である。プロンプトやモデルを変えたときに、変える前後で実行して比べる。

```bash
export ANTHROPIC_API_KEY=...
uv run python apps/api/evals/semantic_diff.py
```

- 実際に API を呼ぶので費用がかかる(1回の実行で1リクエスト)。CI では実行しない
- 一致率は目安であって合否ではない。`warning` と `breaking` の境目は人によっても割れる
- 外れたケースは、モデルの説明を読んで、期待のほうが間違っていないかも確かめる
